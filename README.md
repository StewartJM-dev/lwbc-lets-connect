# LWBC Let's Connect Podcast — site

Static site for **LWBC Let's Connect Podcast with Pastor Raymond Purdy**
(LWBC Media Ministry, Living Word Baptist Church, Sweet Valley, PA).
Pure HTML/CSS/JS, no build step — deploys straight to GitHub Pages.

Companion to the Question Mark site (`StewartJM-dev/the-question-mark`).
Same structure, same code; only branding, copy, and the episode filter
direction differ.

## Pages
- `index.html` — Home (banner → welcome → circular tile nav → footer)
- `about.html` — About
- `episodes.html` — Episodes (auto-pulled from RSS, Question Mark filtered out)
- `submit.html` — Ask a Question (mailto form)
- `subscribe.html` — Subscribe (platform links)

**Footer hotspots.** The footer is one image with invisible clickable
regions positioned by percentage in `css/style.css` (`.fh-*` rules).
The placeholder `footer.jpg` draws those regions as blue boxes. If
Gordon's footer graphic puts the logo / nav words / address somewhere
else, adjust the `.fh-*` percentages to match.

## Episode filter (the one real code difference)

`js/episodes.js` loads the full PodPoint channel feed
(`https://podpoint.com/feed/12205`) and **hides** Question Mark episodes:

1. Titles in `QUESTION_MARK_TITLES` — the frozen list of pre-convention
   QM episodes (same list as the QM site; keep them in sync).
2. Any title starting with the words "Question Mark" (any punctuation
   after) — the naming convention going forward, zero upkeep.

Everything else in the channel shows here. If a QM episode leaks onto
this site, Gordon titled it without the prefix — add it to the list or
ask him to retitle. Set `FILTER_ENABLED = false` to show the whole channel.

- [ ] Replace every placeholder in `images/` (table above)
- [ ] Domain: replace `https://YOUR-DOMAIN-HERE` in every `.html`
      (canonical + og/twitter tags), `sitemap.xml`, `robots.txt`;
      add a `CNAME` file if using a custom domain
- [ ] `submit.html`: set `SHOW_EMAIL` (currently `CHANGE-ME@example.com`)
- [ ] Review copy marked `<!-- COPY REVIEW -->` in `index.html` and `about.html`
- [ ] Confirm the footer graphic keeps the "Built by Covenant Creation & Design" credit
- [ ] Add a Google Search Console verification tag if wanted (QM's was removed)
- [ ] Optionally tune `--accent-gold` / `--accent-blue` in `css/style.css`
      once the real crest is in — the gold is a first pass from the logo

## Deploying

1. Create the repo (suggested: `StewartJM-dev/lwbc-lets-connect`) and push to `main`.
2. Settings → Pages → source `main` / root.
3. Actions tab → run "Update episode feed" once so `data/episodes.json`
   exists (needs a token with `workflow` scope to push the workflow file;
   otherwise add it via the web UI). Until then the site falls back to a
   live CORS-proxied fetch.
